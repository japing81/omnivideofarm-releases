# omnivideofarm-releases

OmniVideoFarm(옴니비디오앱 — 원고에서 장면 그림·음성·자막 영상까지 만드는 판매용 데스크톱 앱) **배포 전용** 공개 저장소입니다. 소스 코드는 없습니다(소스 저장소는 비공개).

여기에 있는 것:

| 위치 | 내용 |
|---|---|
| [Releases](../../releases) | 설치 파일(Windows `OmniVideoFarm-Setup-<버전>.exe`·`.blockmap`), 자동 업데이트 정보 `latest.yml` |

- 앱은 켤 때와 6시간마다 이 저장소의 최신 릴리스를 확인하고, 새 버전을 받아 둡니다. 설치는 사용자가 설정에서 [다시 시작해 설치]를 누를 때만 합니다.
- 설치 파일은 아직 코드 서명이 없습니다. Windows 에서 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요.
- 이 저장소의 파일은 운영자가 직접 올립니다. 손으로 고치지 마세요.
